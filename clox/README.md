clox
====

C implementation of the Lox interpreter from [Crafting Interpreters](https://craftinginterpreters.com/).

## Build & run

Build the `clox` executable:

```sh
make
```

Run the interpreter:

```sh
./clox
```

Alternatively, build and run it with a single command:
```sh
make run
```

Remove all generated build artifacts:

```sh
make clean
```
